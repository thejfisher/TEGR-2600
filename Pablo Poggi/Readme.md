# Entangled states from sparsely coupled spins for metrology with neutral atoms

This is a dataset which contains the csv files of the data points and small simplified scripts that are needed for recreating the figures 1(a-d), 2, 3, 4b, S1, S2, S3 (supplementary material) that are produced by Sridevi Kuriyattil (University of Strathclyde and University of Oxford) in the Journal Article *Entangled states from sparsely coupled spins for metrology with neutral atoms* accepted in PRL on 02 June 2025

The folder PUREdata is further divided into multiples folders
Each Folder `Fig_#` contains the data points of the relevant figures in the **main text**. 
Folders `SFig_#` contains the data points of the relevant figures in the **supplementary material**. 
Please replace `#` with the relevant figure number.

Folder `scripts` contains small scripts which recreates the simplified versions of the relevant figures.

For the details, please refer to the individual README files within the folders.

Any known constants that are plotted are mentioned in the published text and they are also hard coded in the scripts in this dataset.
