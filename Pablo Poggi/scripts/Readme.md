# SCRIPTS
This folder contains the scripts `FIG#.py` and `SFIG#.py` for recreating the following figures:
1(a-d), 2, 3, 4b, S1, S2, S3

`#` is replaced with the relevant figure number.

Scripts are tested with `Python 3.8.11` with dependencies :
   * `numpy` version `1.20.3`
   * `matplotlib` version `3.4.2`
