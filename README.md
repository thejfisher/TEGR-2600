## 📂 What's Inside & What Everything is Used For

### 1. The Core Engine Architecture
These files constitute the actual simulation environment. They handle the Finite-Difference Time-Domain (FDTD) wave propagation, particle kinematics, and the topological scaling of the coordinate metric.

- **`engine.py`**  
  The heart of the TEGR 2600 framework. It integrates the field density ($\vert\phi\vert$) and dynamically calculates the spatial impedance tensor (wave speed $c_w$, damping $\lambda$, and cross-coupling $\beta$) across the grid. It manages the continuous evolution of the metric and the discrete kinematics of the test particles.
  
- **`config_schema.py`**  
  The configuration blueprint. This file contains the data structures and preset configurations that dictate the initial conditions (e.g., baseline wave speeds, grid size, CFL parameters) for different experimental runs.

### 2. The Verification Scripts (Reproducing the Paper)
Each script below corresponds to a specific phase and section of the manuscript. By running these scripts, you will execute the exact tests used to generate the data for the paper.

- **`geometric_clean_test.py`** *(Maps to Section 5: The Geometric Series Test)*  
  Runs a 3-tier artificial boundary simulation (Grandparent $\rightarrow$ Parent $\rightarrow$ Child) to prove that the transformation operator $\mathcal{F}$ is self-similar. It verifies that when impedance scaling is perfectly geometric ($2.0\times$ per boundary), the kinetic suppression of a projectile crossing the horizon is identical (within a $0.05\%$ deviation).

- **`emergent_horizon_test.py`** *(Maps to Section 6.1: Emergent Horizon Formation)*  
  Removes the artificial boundaries and allows the event horizon to emerge dynamically. It couples the local speed of light directly to the scalar field density ($\vert\phi\vert$), proving that the FDTD wave mechanics spontaneously establish a classical gravitational well without hardcoded boundary geometry.

- **`black_hole_battery.py`** *(Maps to Section 6.2 & 6.3: Universal Dimensionless Testing)*  
  The definitive scale-invariance stress test. This script varies the spatial scale of the engine across multiple orders of magnitude to prove that the dimensionless kinematic suppression ratio is a universal constant. If you run this script, you will see the engine output the exact fractional retention ratio of **$1.000093$**, proving the mathematics apply to both stellar-mass and ultramassive black holes universally.

- **`phase5_sindy_v3.py`** *(Maps to Section 6.4: Differential Structure of the Emergent Well)*  
  Utilizes the PySINDy (Sparse Identification of Nonlinear Dynamics) library to extract the literal differential equations governing the particles. It runs an impedance isolation test to definitively separate true geometric kinematics from the structural force artifacts caused by Pauli exclusion and pilot wave density inside the well.

- **`ton618_dimensional_scaling.py`** *(Maps to Section 7.5: The TON 618 Dimensional Anchor)*  
  A non-simulation mathematical script that anchors the dimensionless FDTD grid to physical reality. Using the ultramassive black hole TON 618 as the anchor, it outputs the exact SI conversion matrix (calculating that 1 grid cell $\approx$ $0.01$ light-years, and 1 tick $\approx$ $2.35$ hours), and projects the absolute size and mass limits of "Universe Zero."

## 🛠 Installation & Execution

To run these simulations, you will need **Python 3.9+**. 

1. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
   *(Dependencies include `numpy`, `matplotlib`, and `pysindy`)*

2. Execute any of the experimental scripts to reproduce the results. For example:
   ```bash
   python black_hole_battery.py
   ```

All analytical metrics (e.g., suppression ratios, thermodynamic entropy gradients, coefficient values) will be printed directly to the standard output, and real-time visualization plots will be generated to display the spacetime geometry and particle kinematics.
